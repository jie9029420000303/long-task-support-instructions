# 真人QA驗收腳本：{系統或任務名稱}

監督依本範本撰寫，存成 run 目錄的「真人QA驗收腳本.md」。大括號是要填的內容，填完刪掉大括號與說明文字。

## 給執行本腳本的 AI

你會拿到這份腳本和一位真人QA。請照下列方式進行：

1. 依「情境清單」的順序帶著真人逐步操作。每一步先說明要做什麼、預期會看到什麼，再請真人動手或由你操作。
2. 每一步做完，自己記下實際結果，包括畫面或回應內容、和預期是否相符、截圖或輸出檔路徑。真人確認或補充後一起記下。
3. 結果和預期不符時，當場記成問題，寫下重現步驟、預期、實際、截圖、當時的帳號與資料。接著照該情境寫的「不符時」處理方式繼續或跳到下一個情境。不要自己修改系統或資料去讓它通過。
4. 本腳本沒寫明的不可逆操作一律不做，例如刪除正式資料、對外寄信、付款、送出正式申報。遇到時記成問題並詢問真人。
5. 「真人判斷點」由真人決定結果，你只記錄他的判斷和理由。
6. 全部走完，依[真人QA驗收結果格式](真人QA驗收結果格式.md)產出「真人QA驗收結果.md」，交給真人QA轉回監督。中途停止也要產出，並在總結寫明沒做完的情境和原因。

# 敏感輸出保護

開工 prompt 要求執行端在自己的派工中將以下要求原樣交給子代理；監督自己也遵守。密碼、權杖、驗證碼、cookie、帶存取憑證的網址及其他敏感連線資料，不得出現在對話、工具輸出、工作包、版本控制或一般日誌。不得把秘密放進命令列參數；依既有授權使用安全的憑證來源，不讀出秘密給人看。

可能輸出敏感值的非互動指令，執行前先安排標準輸出與標準錯誤輸出的保護；可使用本技能 `scripts/sensitive-output.cjs`：

```sh
node <skill>/scripts/sensitive-output.cjs --log-dir <已存在的私密工作目錄> -- <指令> [不含秘密的參數...]
```

工具直接啟動指令、不經 shell，將 stdout 與 stderr 合併寫進新建的私人目錄及 `output.log`（目錄設 0700；檔案權限不寬於 0600，受系統 umask 影響可能更嚴），對外只顯示成功或失敗與紀錄位置，並以子程序的退出碼反映結果；啟動失敗只顯示狀態及紀錄位置，不輸出原始錯誤。它不接互動輸入，不能包住互動式登入。不要把秘密或含秘密的網址放在命令列、路徑或檔名；工具不會判斷參數是否含秘密，也無法保護指令自行寫出的其他檔案、網路輸出或工具外的操作。請選可信且不同步雲端的私人工作目錄；權限位元不保證排除額外 ACL 或同步機制。私密紀錄仍可能含秘密，不得直接貼出、提交或送往對話；先確認診斷與驗收所需證據完整，尚需且唯一的原始證據依任務安全規則安全保存，不得刪除；可安全清理的本次私密中間紀錄再依適用規則清理，保留可驗證且已去敏的完整測試結果與診斷證據。收到中斷或終止訊號時工具會轉交同一程序群組並等待子程序結束；自行脫離程序群組的後代或忽略訊號的程序不保證被停止，需自行核對。

讀設定或診斷時只輸出預先確認安全的欄位名稱、狀態、退出碼與必要的非敏感錯誤類型；不要直接印完整設定、原始 stdout／stderr、命令或存取網址。需要查私密紀錄時，在本機以不輸出秘密的方式查證，保留可供診斷的安全摘要；若不能確認輸出安全，先處理該項再繼續，不以顯示秘密換取診斷。此工具是輔助，不能保證所有秘密都被攔住。
